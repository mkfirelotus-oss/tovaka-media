# tovaka-media

Public social video and image assets for Tovaka Builds. These files are already meant to be public (they go out on Tovaka Builds social channels).

## How to use

Each file has a direct download link that Buffer and other schedulers can fetch:

https://raw.githubusercontent.com/mkfirelotus-oss/tovaka-media/main/<path>

Example: https://raw.githubusercontent.com/mkfirelotus-oss/tovaka-media/main/reels/2026-11-13/2026-11-13-tovaka-burn-it-down.mp4

Layout: reels/YYYY-MM-DD/<file>.mp4. Keep each file under 100 MB. Only public media goes here: no secrets, notes, or business files.
